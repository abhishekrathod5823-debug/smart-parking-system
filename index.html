    How It Works

    Buttons: a 10k pull-up keeps E_IN / X_IN at 1. Pressing the switch connects it to ground, so the pin goes 0.

    NOT gates flip it to active-high ENT / EXT.

    AND + NOT (FULL): ENT_OK = ENT AND (NOT FULL). A car cannot enter when Q2 = 1 (count 4).

    NAND + NOT (EMPTY): EXT_OK = NOT( EXT NAND (NOT EMPTY) ). A car cannot exit at count 0.

    XOR: CLK = ENT_OK XOR EXT_OK. One valid press makes one clock pulse; pressing both together cancels out.

    Counter (74HC191): counts up on ENTER, down on EXIT (D/U = EXT_OK). It counts only on the rising edge of CLK, so holding a button counts once. 3 bits (Q2 Q1 Q0) are needed because 2 bits stop at 3.

    OR / AND / NOR decoder: L2 = Q1+Q2, L1 = L2+Q0, L3 = Q2 + Q1.Q0, L4 = Q2, FULL = Q2, EMPTY = NOR(L2, Q0). Each output drives an LED through a 330 ohm resistor.
